Hey there! 

After-Exam is a 2D action-platformer game inspired by the Metroidvania genre.
This project was developed as a partial requirement for CMSC 131 – Special Topics.

How to Play the Game?

You can run After-Exam in two different ways:
Option 1: Play Using a Game Boy Emulator
  1. Install any Game Boy emulator on your device (e.g., SameBoy, mGBA, KiGB).
  2. Download this repository.
  3. Go to the /build folder.
  4. Download the After-Exam ROM ZIP file.
  5. Load the ROM in your emulator and play.

Option 2: Open the Project in GB Studio
  1. Install GB Studio (version 3.2 or later).
  2. Download this repository.
  3. Open GB Studio and load the project file: "After-Exam.gbsproj"
  4. Run or edit the game directly from GB Studio.

Enjoy playing!
